## Thuật ngữ

<!-- Only words specific to Viewer Hub, A–Z. A row starting with [if:<module key>] shows only while that module is
     on. Common IT words stay out. First section of /help. -->

| Thuật ngữ | Nghĩa |
|---|---|
| **Addon** | Tính năng thêm, do admin gửi dưới dạng file `.zip`, cài ở **Cài đặt → Addon**. Cài xong hiện thành một mục mới trên menu. Xem mục **Addon**. |
[if:codemap]| **Bằng chứng** (Code map) | File và dòng code cho thấy một liên kết là có thật. Xem ở khung chi tiết khi bấm một ô. |
| **Chế độ chỉ đọc** | Banner đỏ ở Trang chủ. Viewer Hub thấy dữ liệu do bản mới hơn ghi, hoặc nâng cấp dữ liệu bị lỗi, nên chỉ cho xem và không ghi gì, để dữ liệu của bạn an toàn. Liên hệ admin. |
| **Data pack** (file `.sapack`) | Gói dữ liệu admin đóng sẵn: Code map, F-Search, có thể kèm CSV và Docs. Nạp ở **Cài đặt → Data pack → Import .sapack**. Dữ liệu trong pack có nhãn [icon:inventory_2] **Data pack**, chỉ đọc, và gói mới không ghi đè dữ liệu của bạn. |
[if:codemap]| **Knowledge (KB)** (Code map) | Phần bạn (và AI) thêm vào Code map: ghi chú, quy tắc nghiệp vụ, tài liệu luồng, liên kết tay. Lưu trên máy bạn, không mất khi có data pack mới. |
[if:codemap]| **Liên kết tay** (Code map) | Liên kết bạn tự thêm khi Code map không tự thấy lời gọi. Hiện bằng nét đứt với chữ "tay". |
[if:codemap]| **Luồng** (Code map) | Đường đi từ một màn hình, API hoặc job qua các bước tới bảng dữ liệu cuối cùng. |
| **Mã mở khoá** | Chuỗi do admin gửi để mở tính năng Premium. Dán ở mục **Premium** trên menu (chỉ có khi đang có tính năng bị khoá); mở một lần là dùng được mãi. |
[if:codemap]| **Node** (Code map) | Một ô trên sơ đồ: màn hình, API, method, procedure, bảng hoặc job. |
| **Premium** | Đây là tính năng mà admin không muốn cho bạn sử dụng. Liên hệ admin để lấy key mở khoá. |
| **Thư mục dữ liệu** | Nơi lưu mọi thứ của bạn (CSV, Docs, ghi chú, addon), tách khỏi thư mục chương trình nên cập nhật bản mới không mất dữ liệu. Xem ở **Cài đặt**. |
[if:codemap]| **Tên logic / tên kỹ thuật** (Code map) | Tên nghiệp vụ (注文明細 / Order Line) và tên trong code hay database (`ORDER_LINE`). Tìm bằng tên nào cũng được. |
| **Tool cho AI** | Từng việc AI làm được qua MCP, liệt kê ở bảng cuối mục của mỗi tính năng. |
