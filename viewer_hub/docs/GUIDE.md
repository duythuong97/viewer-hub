## Docs

Biến một thư mục tài liệu markdown (`.md`) thành trang web có menu và ô tìm kiếm.

Site có nhãn [icon:inventory_2] **Data pack** do admin cung cấp, chỉ đọc (không build lại, không xoá).

1. **Docs** → **Tạo site**.
2. Đặt tên (bỏ trống thì lấy tên thư mục), **Chọn thư mục** (hoặc **Chọn .zip**, hoặc kéo thả thư mục vào) → **Tạo**.
3. **Mở site** để đọc. Site có **một menu bên trái**: thư mục → trang → các tiêu đề trong trang; ô tìm kiếm ở góc trên tìm trong cả site; nút Trước / Sau ở cuối trang.

Sửa tài liệu xong: vào site → **Cập nhật nguồn** (chọn lại thư mục) hoặc **Build lại**. Chỉ file tài liệu được nhận (`.md`, ảnh, `.pdf`, `.csv`…).
